# 🌱 AgriGuard – Smart Agriculture IoT System

AgriGuard is an IoT-based smart agriculture system designed to protect crops from potential wild animal intrusion and support efficient agricultural monitoring through a web-based dashboard.

The project aims to provide a smart solution for monitoring agricultural fields by combining animal intrusion detection with an interactive dashboard for displaying system information.

## 🚀 Features

- **Animal Intrusion Detection:** Uses PIR motion detection and ultrasonic distance measurement to identify potential animal intrusion.
- **Alert System:** Provides visual and audio alerts through an LED and buzzer when intrusion conditions are detected.
- **Web-Based Dashboard:** Provides a centralized interface for monitoring agricultural field conditions.
- **Animal Status Monitoring:** Displays the current field status as Safe or Alert.
- **Responsive UI:** Offers a simple and user-friendly dashboard interface.

## 💻 Dashboard

The web dashboard is designed to provide a clear overview of the system, including:

- Animal intrusion status.
- Safe / Alert indicators.
- Dashboard navigation.
- Sensor monitoring interface.

## ⚙️ Animal Detection Working

1. The PIR sensor detects movement in the monitored area.
2. The ultrasonic sensor measures the distance of the detected object.
3. The ESP32 processes the sensor readings based on predefined conditions.
4. When potential intrusion is confirmed, the buzzer and LED are activated.
5. The detection status can be displayed on the monitoring dashboard.

## 🎯 Objective

To develop an affordable IoT-based agricultural monitoring solution that helps protect crops from animal intrusion, reduces the need for continuous manual supervision, and supports smarter farming practices.
